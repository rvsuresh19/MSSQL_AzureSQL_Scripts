Create a branch
-------------------
git branch feature  => create a branch feature (this will create files from main branch)

git checkout feature ==> to switch to feature branch (or git checkout -b feature1 to create a branch and checkout in a single command)

git branch newfeature feature  ==>(this will create a new branch newfeature from copy of feature)


Push he new branch to origin (github)
-----------------------------
git push --set-upstream origin feature  (or) git push -u origin feature (for first time only after that just "git push" alone is enough)
